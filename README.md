# UPICON Enterprise Portal - React.js Application

Converted from Static HTML/CSS/JS to React 18 + Vite with 1:1 UI design parity.

## Project Structure
- `src/assets/`: Images, icons, fonts, and global stylesheets
- `src/components/`: Reusable components (common, layout, sections)
- `src/pages/`: Page-level components
- `src/layouts/`: Layout wrappers (MainLayout, AuthLayout)
- `src/routes/`: AppRoutes routing configuration
- `src/hooks/`: Custom hooks (useFetch, useInteractiveEffects)
- `src/services/`: API services
- `src/utils/`: Helpers & validation utilities
- `src/context/`: Application context

## Available Scripts
- `npm run dev`: Runs local development server
- `npm run build`: Builds production bundle in `dist/`
- `npm run preview`: Previews production build
